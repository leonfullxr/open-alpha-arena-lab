# Open Alpha Arena Lab

An open laboratory for AI trading experiments. Paper trading only, independent virtual accounts, and public decision evidence. Original implementation; not affiliated with Nof1.

The editorial landing and the simulation are separate experiences. Default startup will use a deterministic offline demo without credentials or external calls.

Implementation is in progress. See [implementation status](docs/implementation-status.md) and [architecture decisions](docs/architecture.md). Production deployment is pending review.
