A Canvas2D context alone does not identify fallback mode.

## Selection and interruption

**EXACT — source-derived selection.** Normal document scrolling selects timed stages; it does not scrub every pose. Grid enters at 65% viewport height; later destinations enter at 80%. The first handoff waits for scrolling through 10% of hero-art height. The active/multiple-stage forward gate uses a 60% reading line. Stage flags require 10% viewport movement since the last flag change, with 10% viewport reverse hysteresis. Thresholds remain reachable at the document bottom and are recalculated after fonts, resize and breakpoint changes.

The coordinator maintains one directed adjacent leg, its target endpoint, raw phase and elapsed clock. Reversal preserves that phase and the original directed geometry/assignment. Returning toward either endpoint retimes the remaining portion instead of restarting. Ordinary skips settle intermediate state and animate the last adjacency. A single event over 1.5 viewport heights and 15 viewport heights/second snaps to its absolute destination. Restored-scroll initialization settles a coherent current stage. Resize, font loading and anchor reflow re-derive the stage only when width or measured anchor positions change, snapping once if it differs; a viewport-height-only resize (mobile URL bar) keeps the current stage, and an in-flight leg that still matches keeps its clock, assignment and landed state.

One animation scheduler owns transient painting. Anchors are measured in document coordinates when geometry changes; current scroll is subtracted for viewport-space drawing. Decorative transfer canvases add no document height. Idle artwork does not have an orbit, bob, pointer parallax or spring.

## Fallback and failure

**OBSERVED FALLBACK — calibrated, not an exact measured duration.** When WebGL2 is unavailable, 600 ms stationary source/destination crossfades replace native spatial flights. Mountain fades at its anchor as the grid appears; the selected profile gives way to a gold chart; chart fills fade while the already distributed lattice appears; lattice fades as the complete OA mark appears. The 600 ms fallback duration is configurable calibration, not a claim that the earlier recordings established an exact canvas duration. Chart formation/separation and retained context follow the exact timings above.

Reduced motion renders settled static artwork at all anchors, including the split chart and its labels. Complete Canvas failure exposes canonical SVG artwork and the DOM scaffold/annotations. WebGL context loss hides stale GPU pixels, schedules the Canvas fallback, and restoration rebuilds shader resources and invalidates cached stills. The nonvisual `data-renderer` diagnostic reports `webgl2+canvas2d`, `canvas2d-fallback` or `svg-static`.

## Acceptance limits

Native geometry, shaders, clocks and assignments have authoritative implementation evidence. Static captures and interaction checks cover the requested five viewports. The motion capture tool samples actual Canvas illustration layers inside animation callbacks and records actual elapsed times; text and DOM scaffolding are excluded. Copies add instrumentation overhead, so these samples are not a calibrated 60 fps recording. Complete full-page frame-by-frame parity and physical GPU/Safari behavior remain NATIVE TO VERIFY. The local software-WebGL comparison, own project text/mark and changed browser scrollbar width are stated explicitly instead of being presented as an exact full-page replica certification.
