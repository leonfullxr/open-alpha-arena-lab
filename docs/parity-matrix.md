# Parity and experiment profiles

This project is independent of Nof1. A similar information architecture does not establish an identical experiment or financial simulator.

| Category | Verified reference evidence | Community inference | Our choice |
| --- | --- | --- | --- |
| Landing | Local nine-page PDF records desktop geometry, five visual stages, CSS timings | Exact proprietary geometry and flight paths are unrecovered | Original deterministic geometry, Newsreader OFL, adapted branding |
| Interface | Public captures and community UI show equity chart, activity column and model account tiles | Mock UI cannot establish live backend behavior | Typed real API and persistent deterministic replay |
| Baseline | Shared information and independent virtual accounts are described publicly | Exact original prompts, margin/execution internals unavailable | Frozen common prompts/snapshots; six crypto perps; virtual $10,000; 180-second cadence |
| Execution | No proprietary matching code verified | Prior clones differ in fees, margin and risk | Paper-only Decimal ledger; fresh executable quotes; explicit fees/funding and estimated liquidation |
| Research | FinMem/TradingAgents are research hypotheses | Memory or collaboration may help in some historical settings | Separate extended competitions and ablations; no performance guarantee |

`alpha_2025_baseline` permits private weights under common published settings, prompts, inputs and execution rules. `research_extended` identifies differences in strategies, tools, assets, memory, collaboration and execution; its rankings are separate. Confidential strategies are deferred. The 220 landing silhouettes are conceptual artwork, not a claim about active models. The six-span chart is conceptual artwork, not performance.

Publication defaults to exact prompts and public-safe inputs, decisions and justifications, risk evaluations, executions, fees, funding, equity and failures. No credentials, transport headers, personal information or hidden provider reasoning is published. Prompt downloads must preserve sent bytes and content hashes.
